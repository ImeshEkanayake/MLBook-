# ML Book — executable examples

Self-contained notebooks for learning how applied machine-learning models work, how to choose their settings, and how to check their limits. This companion repository belongs to the ML Book project; the book manuscript and its planning files are maintained separately.

**Start here:** [code_001 — Decision trees](notebooks/001_Chapter_18_01_Decision_Tree.ipynb), for Chapter 18.1. It contains a model guide, a mechanism diagram, executed tree/boundary figures, controlled experiments covering all 13 `DecisionTreeClassifier` constructor parameters, an interaction study, a protected final assessment and eight exercises. It generates all data locally. The five [Chapter 1 concept notebooks](CHAPTER_01_GUIDE.md) now accompany it, covering task framing, prediction/discovery, generation/simulation/inversion, decisions and representations. Five [Chapter 2 mathematics laboratories](CHAPTER_02_GUIDE.md) cover arrays, geometry, derivatives, optimization and scientific numerics. Five [Chapter 3 statistics laboratories](CHAPTER_03_GUIDE.md) develop probability, sampling, estimation, comparisons and uncertainty. Five [Chapter 4 learning laboratories](CHAPTER_04_GUIDE.md) connect parameters, objectives, updates, reusable state and diagnostics. Five [Chapter 5 generalization laboratories](CHAPTER_05_GUIDE.md) connect populations, capacity, preferences, learning curves and assumptions. Five [Chapter 6 learning-paradigm laboratories](CHAPTER_06_GUIDE.md) distinguish supervision, structure, masking, transfer and action feedback. Five [Chapter 7 experimental-practice laboratories](CHAPTER_07_GUIDE.md) connect baselines, leakage, provenance, matched comparisons and causal limits. Five [Chapter 8 dataset-construction laboratories](CHAPTER_08_GUIDE.md) build targets, joins, historical features, sampling records and storage views. Five [Chapter 9 exploration laboratories](CHAPTER_09_GUIDE.md) connect distributions, conditional relationships, coverage, dependence and a recorded final hypothesis check. There are 120 completed notebooks and no placeholder notebooks.

## Quickstart

The verified environment is **CPython 3.14.3, CPU only**, on macOS ARM64. Direct package versions are pinned in [requirements.txt](requirements.txt); the complete tested package set is recorded in [requirements-lock.txt](requirements-lock.txt). Other OS/Python combinations have not been verified. The notebook prints its actual environment. Initial package installation uses the internet; normal notebook execution does not.

```bash
git clone https://github.com/ImeshEkanayake/MLBook-.git
cd MLBook-
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
python scripts/run_notebook.py
```

The runner starts a fresh kernel using that exact Python interpreter, runs every cell, stops on errors and saves a new executed copy under `build/`. It does not require registering a system-wide Jupyter kernel or importing project modules into the example. A successful run prints all 13 parameter names, actual final metrics and runtime. The committed notebook already contains its reference outputs for reading on GitHub.

To experiment interactively, open the notebook in a notebook-capable editor and select `.venv/bin/python` as its kernel. Alternatively install a Jupyter frontend into the environment (`python -m pip install jupyterlab`, an optional frontend not included in the reference lock) and run `jupyter lab`. Restart the kernel and run all cells before relying on results. Windows users can create the environment with their Python 3.14 launcher and activate `.venv\Scripts\Activate.ps1`; that platform is not part of the verified run.

The reference notebook is deliberately small: 1,800 main observations and small auxiliary datasets, no GPU, Graphviz installation, downloads, credentials or external helper files. See [EXECUTION_REPORT.md](EXECUTION_REPORT.md) for measured timing and results. Allow 60–90 minutes to read, predict outcomes and try the exercises. The generated scores describe synthetic teaching data, not structural reliability or production performance.

## Finding and linking examples

- [CODE_EXAMPLES.md](CODE_EXAMPLES.md) is the stable human-readable code directory.
- [examples.json](examples.json) is its machine-readable counterpart, with paths, book mapping, tested environment and execution status.
- [AUTHORING_GUIDE.md](AUTHORING_GUIDE.md) defines the notebook format, experimental design, visual conventions and acceptance checks.

The book uses a visible permanent identifier with an actual Markdown destination:

```markdown
[#code_001](https://github.com/ImeshEkanayake/MLBook-/blob/main/CODE_EXAMPLES.md#code_001)
```

A bare `#code_001` is text, not an automatic remote hyperlink. The registry anchor remains stable if a chapter or filename changes; update its notebook destination and the JSON record together. For print, retain the readable code ID and provide this repository's code directory URL. Do not rely on a chapter number as the permanent identity.

Current filename: `001_Chapter_18_01_Decision_Tree.ipynb`. The first field corresponds to `code_001`; `18_01` maps to Chapter 18, subtopic 18.1. Keep the correctly spelled `Chapter` and a descriptive underscore-separated topic. Never reuse a retired code ID.

## Reproducing and maintaining outputs

The committed example is executed, with modest inline PNG figures and numeric tables. Large datasets, environments, caches, checkpoints and generated build outputs are ignored. All example data generation, imports and helper definitions live inside the notebook, so it can be copied and run independently once dependencies are installed. The runner is a convenience, not a hidden notebook dependency.

Use training/validation for exercises and choices; treat the final test as spent after reading it. When changing code, rerun in a fresh kernel, inspect figures and update the execution report/registry from real output. To intentionally replace the reference notebook with a newly verified run:

```bash
python scripts/run_notebook.py --output notebooks/001_Chapter_18_01_Decision_Tree.ipynb
```

Review changes before committing. Do not publish private datasets, credentials, unrelated manuscript files or the user's visual reference attachment. The repository contains the complete tree laboratory and twenty executed Chapter 1–4 concept/mathematics/statistics/learning notebooks, plus an authoring standard. It does not yet implement the remaining book chapters.
